El comando whoami muestra el nombre del usuario que está utilizando el sistema actualmente. Esta información es útil para identificar qué cuenta está ejecutando tareas o administrando un servidor.

El comando uname -a muestra información general del sistema operativo, incluyendo nombre del sistema, versión y arquitectura. Esta información es útil para conocer las características del entorno donde se ejecutan los servicios y facilitar tareas de administración y soporte.
