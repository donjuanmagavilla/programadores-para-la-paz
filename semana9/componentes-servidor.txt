Sistema operativo:
Es el software principal del computador o servidor. Administra los recursos del sistema y permite ejecutar aplicaciones.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador y crear aplicaciones del lado del servidor.

Aplicación server.js:
Es el archivo que contiene la lógica de la aplicación web. Define las rutas y respuestas que ofrece el servidor.

Puerto:
Es un punto de comunicación utilizado por las aplicaciones para recibir solicitudes. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros que almacenan eventos, actividades y errores del sistema. Ayudan a supervisar y diagnosticar problemas en el servidor.
